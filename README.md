# Healthcare UX System Intelligence Dashboard

A premium, data-driven, visually stunning web application that presents system intelligence for a healthcare enterprise UX organisation.

## 🎨 Features

- **10 Scroll-Driven Sections** with smooth animations
- **Dark Theme** with glassmorphism UI
- **Premium Design** inspired by Apple, Linear, and Stripe
- **Interactive Visualizations** using Recharts and D3
- **Framer Motion Animations** for smooth transitions
- **Responsive Design** optimized for all screen sizes

## 📊 Sections

1. **Hero** - Immersive entry with animated counters
2. **Healthcare Context** - Explaining Payment Integrity, Care Management, CSR workflows
3. **Team Analytics** - Data visualizations of team composition
4. **Project Ecosystem** - Relational view of systems and projects
5. **AI Intelligence Layer** - Glowing visualization of AI projects
6. **Problem Heatmap** - Animated bars showing systemic challenges
7. **System Architecture** - Interactive network graph of connected systems
8. **Insight Layer** - Executive cards with strategic observations
9. **Action Framework** - Strategic recommendations
10. **People Directory** - Team member cards with expandable details

## 🚀 Getting Started

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

The application will be available at `http://localhost:5173`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## 🛠️ Tech Stack
